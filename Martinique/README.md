# Martinique | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of the **entire island of Martinique** (France), from Fort-de-France and Aimé Césaire airport to Le Robert, Rivière-Salée and Sainte-Luce.

### ✨ Features

- 🏙️ Buildings from OpenStreetMap (binary format)
- 👥 **144,000+ simulated commuters** from real INSEE census data (Filosofi 2021, mobility flows 2021)
- 🎓 **Realistic traffic generators**: Aimé Césaire airport, Université des Antilles (Schœlcher), CHU Martinique - Pierre Zobda-Quitman, Terminal croisière Pointe Simon
- ✈️ **Aéroport Martinique Aimé Césaire** (Le Lamentin), runways and taxiways
- 🌊 **Ocean depth data** — the Caribbean Sea/Atlantic coastline is fully modelled with depth contours
- 🏛️ **Building & ocean foundations** layers enabled
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Martinique` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **France** tab → **Martinique**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant l'**île entière de la Martinique**, de Fort-de-France et l'aéroport Aimé Césaire au Robert, à Rivière-Salée et à Sainte-Luce.

### ✨ Contenu

- 🏙️ Bâtiments OpenStreetMap (format binaire)
- 👥 **Plus de 144 000 actifs simulés** (INSEE Filosofi 2021, mobilités 2021)
- 🎓 **Pôles de trafic** : aéroport Aimé Césaire, Université des Antilles (Schœlcher), CHU Martinique - Pierre Zobda-Quitman, terminal croisière Pointe Simon
- ✈️ **Aéroport Martinique Aimé Césaire** (Le Lamentin), pistes et taxiways
- 🌊 **Données de profondeur** de la mer des Caraïbes/Atlantique (contours bathymétriques)
- 🏛️ Couches fondations bâtiments et océan activées
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Martinique` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **France** → **Martinique**

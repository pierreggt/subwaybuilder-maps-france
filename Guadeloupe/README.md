# Guadeloupe | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of the **entire Guadeloupe archipelago** (France), from Basse-Terre and Grande-Terre to the outlying islands of Marie-Galante, Les Saintes and La Désirade.

### ✨ Features

- 🏙️ Buildings from OpenStreetMap (binary format)
- 👥 **158,000+ simulated commuters** from real INSEE MOBPRO commute flows (2021), population estimated from OSM building floor area
- 🎓 **Realistic traffic generators**: Guadeloupe - Maryse Condé airport, Université des Antilles, CHU de Guadeloupe (Perrin), cruise terminal, Gare Maritime de Bergevin (inter-island ferries), Jarry industrial/commercial zone
- ✈️ **Guadeloupe - Maryse Condé airport**, runways and taxiways
- 🌊 **Ocean depth data** — the Caribbean coastline (including inter-island crossings) is fully modelled with depth contours
- 🏛️ **Building & ocean foundations** layers enabled
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Guadeloupe` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **France** tab → **Guadeloupe**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant l'**archipel entier de la Guadeloupe**, de Basse-Terre et Grande-Terre aux îles satellites de Marie-Galante, des Saintes et de La Désirade.

### ✨ Contenu

- 🏙️ Bâtiments OpenStreetMap (format binaire)
- 👥 **Plus de 158 000 actifs simulés** depuis les vrais flux domicile-travail INSEE MOBPRO (2021), population estimée depuis la surface de plancher des bâtiments OSM
- 🎓 **Pôles de trafic** : aéroport Guadeloupe - Maryse Condé, Université des Antilles, CHU de Guadeloupe (Perrin), terminal de croisière, Gare Maritime de Bergevin (ferries inter-îles), zone industrielle et commerciale de Jarry
- ✈️ **Aéroport Guadeloupe - Maryse Condé**, pistes et taxiways
- 🌊 **Données de profondeur** de la mer des Caraïbes (y compris les traversées inter-îles), contours bathymétriques
- 🏛️ Couches fondations bâtiments et océan activées
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Guadeloupe` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **France** → **Guadeloupe**

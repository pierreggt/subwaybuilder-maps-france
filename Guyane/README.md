# Guyane | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of French Guiana's **developed coastal corridor**, from Saint-Laurent-du-Maroni and the Guiana Space Centre (Kourou) to Cayenne and its airport. (French Guiana's interior is ~99% uninhabited Amazon rainforest with no road network — this map covers the real, developed part of the territory.)

### ✨ Features

- 🏙️ Buildings from OpenStreetMap (binary format)
- 👥 **83,000+ simulated commuters** from real INSEE MOBPRO commute flows (2021), population estimated from OSM building floor area
- 🎓 **Realistic traffic generators**: Cayenne-Félix Éboué airport, Centre Spatial Guyanais (Guiana Space Centre), Université de Guyane, CHU de Guyane (Cayenne and Saint-Laurent-du-Maroni sites)
- ✈️ **Cayenne-Félix Éboué airport**, runways and taxiways
- 🌊 **Ocean depth data** — the Atlantic coastline is fully modelled with depth contours
- 🏛️ **Building & ocean foundations** layers enabled
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Guyane` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **France** tab → **Guyane**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant le **corridor côtier développé** de la Guyane, de Saint-Laurent-du-Maroni et du Centre Spatial Guyanais (Kourou) à Cayenne et son aéroport. (L'intérieur de la Guyane est ~99% forêt amazonienne inhabitée sans réseau routier — cette carte couvre la partie réellement développée du territoire.)

### ✨ Contenu

- 🏙️ Bâtiments OpenStreetMap (format binaire)
- 👥 **Plus de 83 000 actifs simulés** depuis les vrais flux domicile-travail INSEE MOBPRO (2021), population estimée depuis la surface de plancher des bâtiments OSM
- 🎓 **Pôles de trafic** : aéroport Cayenne-Félix Éboué, Centre Spatial Guyanais, Université de Guyane, CHU de Guyane (sites de Cayenne et Saint-Laurent-du-Maroni)
- ✈️ **Aéroport Cayenne-Félix Éboué**, pistes et taxiways
- 🌊 **Données de profondeur** de la côte atlantique (contours bathymétriques)
- 🏛️ Couches fondations bâtiments et océan activées
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Guyane` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **France** → **Guyane**

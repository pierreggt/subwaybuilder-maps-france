# La Réunion | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of the **entire island of La Réunion** (France), from Saint-Denis and Roland Garros airport to Le Port, La Possession and Saint-Paul.

### ✨ Features

- 🏙️ Buildings from OpenStreetMap (binary format)
- 👥 **307,000+ simulated commuters** from real INSEE census data (Filosofi 2021, mobility flows 2021)
- 🎓 **Realistic traffic generators**: Roland Garros airport, Université de La Réunion (Moufia), CHU Réunion - Félix Guyon
- ✈️ **Aéroport Roland Garros** (Sainte-Marie), runways and taxiways
- 🌊 **Ocean depth data** — the Indian Ocean coastline is fully modelled with depth contours
- 🏛️ **Building & ocean foundations** layers enabled
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Reunion` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **France** tab → **La Reunion**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant l'**île entière de La Réunion**, de Saint-Denis et l'aéroport Roland Garros au Port, à La Possession et à Saint-Paul.

### ✨ Contenu

- 🏙️ Bâtiments OpenStreetMap (format binaire)
- 👥 **Plus de 307 000 actifs simulés** (INSEE Filosofi 2021, mobilités 2021)
- 🎓 **Pôles de trafic** : aéroport Roland Garros, Université de La Réunion (Moufia), CHU Réunion - Félix Guyon
- ✈️ **Aéroport Roland Garros** (Sainte-Marie), pistes et taxiways
- 🌊 **Données de profondeur** de l'océan Indien (contours bathymétriques)
- 🏛️ Couches fondations bâtiments et océan activées
- 🗺️ Fond de carte Protomaps avec eau, parcs et forêts

### 📦 Installation

1. Dans Subway Builder : Paramètres → Mod Manager → **Open Mods Folder**
2. Décompresser et placer le dossier `Reunion` dans `mods`
3. Lancer le serveur : `sh ` + glisser `run_mac-linux.sh` dans le Terminal, Entrée (ou double-clic sur `run_windows.bat`)
4. Activer le mod, redémarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **France** → **La Reunion**

# Besancon | Subway Builder

[🇬🇧 English](#-english) | [🇫🇷 Français](#-français)

## 🇬🇧 English

Subway Builder mod adding a map of the **Besancon metropolitan area** (France), with its tramway network.

### ✨ Features

- 🏙️ Buildings from OpenStreetMap (binary format)
- 👥 **129 356+ simulated commuters** from real INSEE census data (Filosofi 2021, mobility flows 2021)
- 🎓 **Realistic traffic generators**: Universite Marie-et-Louis-Pasteur, CHU Besancon - Jean Minjoz, Gare de Besancon-Viotte
- 🌊 **Ocean depth data** for any nearby waterway/lake
- 🏛️ **Building foundations** layer enabled
- 🗺️ **Protomaps basemap** with water, parks and forests

### 📦 Installation

1. In Subway Builder: Settings → Mod Manager → **Open Mods Folder**
2. Unzip and place the `Besancon` folder inside `mods`
3. Start the tile server:
   - **macOS/Linux**: open Terminal, type `sh ` (with a space), drag and drop `run_mac-linux.sh`, press Enter
   - **Windows**: double-click `run_windows.bat`
4. Enable the mod in Mod Manager, restart the game
5. Main menu: **Ctrl + Shift + R** (Cmd + Option + R on Mac)
6. New Game → **France** tab → **Besancon**

⚠️ Keep the terminal window open while playing.

## 🇫🇷 Français

Mod Subway Builder ajoutant la **metropole de Besancon** (France), avec son reseau de tramway.

### ✨ Contenu

- 🏙️ Batiments issus d'OpenStreetMap (format binaire)
- 👥 **129 356+ trajets domicile-travail simules** a partir de donnees INSEE reelles (Filosofi 2021, flux de mobilite 2021)
- 🎓 **Generateurs de trafic realistes** : Universite Marie-et-Louis-Pasteur, CHU Besancon - Jean Minjoz, Gare de Besancon-Viotte
- 🌊 **Donnees de profondeur d'eau** pour tout plan d'eau/riviere a proximite
- 🏛️ Layer **fondations de batiments** active
- 🗺️ **Fond de carte Protomaps** avec eau, parcs et forets

### 📦 Installation

1. Dans Subway Builder : Parametres → Gestionnaire de mods → **Ouvrir le dossier des mods**
2. Decompresser et placer le dossier `Besancon` dans `mods`
3. Lancer le serveur de tuiles :
   - **macOS/Linux** : ouvrir un Terminal, taper `sh ` (avec un espace), glisser-deposer `run_mac-linux.sh`, appuyer sur Entree
   - **Windows** : double-cliquer sur `run_windows.bat`
4. Activer le mod dans le Gestionnaire de mods, redemarrer le jeu
5. Menu principal : **Ctrl + Shift + R** (Cmd + Option + R sur Mac)
6. Nouvelle partie → onglet **France** → **Besancon**

⚠️ Garder la fenetre du terminal ouverte pendant que vous jouez.
